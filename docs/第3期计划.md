# 第 3 期 · 拓扑 实施计划

> 2026-07-22 制定。前置：第 2 期已完成（指标采集/告警/WS 全链路）。
> 目标：拓扑图自动发现 + 手工连线，链路流量可视化（对标北塔拓扑页）。

## 里程碑

### T1 拓扑数据模型与迁移
- `topo_links` 表：源设备/源端口 ↔ 目标设备/目标端口、来源（manual/lldp/cdp）
- 节点布局：`devices` 表加 pos_x/pos_y（画布坐标持久化，单图先行）
- ops 库手工 ALTER 迁移（沿用 M4 做法）

### T2 LLDP/CDP 自动发现
- `topology/discovery.py`：SNMP 读 LLDP-MIB lldpRemTable / 思科 CDP cdpCacheTable
- 邻居解析到库内设备：优先管理 IP 匹配，其次 sysName↔设备名匹配；解析不到的邻居记为未匹配（不阻断）
- 发现的链路自动入库（source=lldp/cdp），重复链路去重

### T3 拓扑 API
- `GET /api/topology/graph`：节点（设备+状态+坐标）+ 链路（含两端接口最新流量/利用率，取 metrics 最新值）
- 连线 CRUD：`POST/PUT/DELETE /api/topology/links`
- 布局保存：`PUT /api/topology/layout`
- 自动发现：`POST /api/topology/discover`（jobrunner 后台跑，轮询任务结果）

### T4 后端测试
- LLDP/CDP 解析与邻居解析（假 walk 数据）、图数据组装（含流量）、连线/布局 API
- SQLite/PG 双跑

### T5 前端 G6 画布
- AntV G6：深色画布、节点图标+名称+IP、按状态着色（绿/黄/红/灰）
- 浏览/编辑两种模式：拖拽节点、两节点拉线（弹端口选择）、布局保存、自动发现按钮
- 连线标签显示实时流量（bps 格式化），利用率超阈值变色；周期刷新（30s）+ WS 状态推送联动

## 明确不做（本期）

- 多拓扑图/子图下钻（先单图，分组视图后续补）
- 交换机 MAC 转发表推算（无 LLDP/CDP 环境的兜底手段，现场需要再补）
- 链路流量历史曲线（点击链路看曲线放第 4 期）
