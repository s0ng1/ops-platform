# 第 6 期计划 · 网络运维周边（配置备份 / Syslog·Trap / 轻量 IPAM）

> 2026-07-27 定稿。背景：对标北塔差距分析（北塔管理对象 9 大类，平台原覆盖 3.5 类；差距在覆盖面而非现有功能质量）。
> 本期补北塔 BTIM/MC 标配的三个网络运维周边模块。原「第 6 期（现场接入+生产部署）」顺延为第 9 期。

## M1 配置文件备份 + 变更检测

- `collectors/config_backup.py`：asyncssh 跑厂商命令表（H3C/华为 `display current-configuration`、Cisco `show running-config`），留 `run_commands` 注入点
- `config_backups` 表：device_id / content_hash / content / created_at；hash 相同不重复存
- 周期任务注册 scheduler TASKS（6h，适用谓词：network/security 且挂 SSH 凭据）
- 内容变化 → 告警引擎 info 级「配置变更」事件
- API：版本列表 / 单版本内容 / 两版 diff（后端 difflib unified diff）
- 前端：设备详情加「配置备份」tab（版本列表 + diff 视图）；设备表单对 network/security 放开 SSH 凭据选择
- 真机验证：H3C 192.168.8.1 若开 SSH 则实测，否则 mock + 现场联调

## M2 Syslog / SNMP Trap 接收 → 告警

- `core/logreceiver.py`：asyncio UDP 接收器，端口 OPS_SYSLOG_PORT=1514 / OPS_TRAP_PORT=1162（避开特权端口，可配），挂 lifespan（同 monitor_loop 模式）
- Syslog 按 RFC3164 解析（pri→facility/severity、host、message）；Trap 用 pysnmp 7.1 接收 API 解 OID/varbinds
- `log_events` 表：source_ip / kind(syslog|trap) / facility / severity / message(JSON) / created_at
- `log_rules` 表：源 IP/关键字/severity 匹配 → 命中进告警引擎
- API：事件查询（过滤+分页）、规则 CRUD
- 前端：告警中心加「日志事件」tab + 规则 CRUD
- 冒烟：本机发测试 syslog 报文验证落库+规则命中

## M3 轻量 IPAM

- `ip_inventory` 表：ip / mac / hostname / 接入设备+端口 / 首见时间 / 最近在线 / 来源(ping|arp|mac_table)
- 数据来源：①现有 IP 段扫描结果回写 ②交换机 SNMP walk dot1dTpFdbTable（MAC→端口）+ ipNetToMediaTable（IP→MAC）——顺带补上总体方案「SNMP-ARP 未移植」的坑
- 采集任务 300s（network/security 设备）
- 新 MAC 首见 → 「新终端接入」事件（白名单机制可静默）
- API：子网维度汇总 + 终端清单（过滤+分页）
- 前端：`/ipam` 页（子网 IP 使用状态网格：在线/近 7 天活跃/未见 + 终端清单）
- 真机验证：对 H3C 192.168.8.1 walk MAC/ARP 表
