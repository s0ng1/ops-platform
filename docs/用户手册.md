# 内网运维管理平台 · 用户手册

- 版本：v1.0
- 日期：2026-07-29
- 适用对象：日常使用平台进行监控、告警处理与资产维护的运维人员

---

## 1. 登录与角色权限

本章说明如何登录平台、三种角色分别能做什么，以及界面顶栏各指示的含义。

### 1.1 登录

浏览器访问 `http://<平台地址>:<端口>`（默认 8080 端口，以管理员通知为准），在登录页输入用户名、密码，回车或点「登 录」进入系统，默认进入「仪表盘」。登录态默认 12 小时有效，过期后操作会跳回登录页重新登录。

初始账号与密码由管理员部署时在 `.env` 中设定（默认用户名为 `admin`），**首次登录后请立即修改密码**（见第 14 章）。

### 1.2 角色权限对照表

平台有三种角色：管理员（admin）、操作员（operator）、只读用户（viewer）。权限由服务端统一控制：

| 功能 | 管理员 admin | 操作员 operator | 只读用户 viewer |
|---|---|---|---|
| 查看仪表盘/拓扑/总线/设备/告警/报表/大屏/IPAM/凭据列表 | ✓ | ✓ | ✓ |
| 报表导出 Excel | ✓ | ✓ | ✓ |
| 设备新增/编辑/删除、立即探测 | ✓ | ✓ | 后端拒绝（403） |
| 凭据新增/编辑/删除 | ✓ | ✓ | 后端拒绝（403） |
| 告警事件确认/关闭 | ✓ | ✓ | 后端拒绝（403） |
| 告警规则/规则模板/通知渠道/静默窗口/日志规则维护 | ✓ | ✓ | 后端拒绝（403） |
| 拓扑连线/删链路/保存布局/拓扑自动发现 | ✓ | ✓ | 后端拒绝（403） |
| 「自动发现」发起扫描与批量入库 | ✓ | ✓ | 后端拒绝（403） |
| IPAM 白名单开关、备注编辑 | ✓ | ✓ | 前端禁用 |
| 设备详情「配置备份 → 立即备份」 | ✓ | ✓ | 前端不显示该按钮 |
| 设备配置备份「查看全文 / 对比版本」 | ✓ | ✓ | 前端不显示，后端拒绝（403） |
| 「用户管理」「审计日志」菜单与页面 | ✓ | 无此菜单 | 无此菜单 |
| 修改自己的密码 | ✓ | ✓ | ✓ |

> 说明：除上表标注「前端禁用/不显示」的入口外，多数页面的操作按钮对所有登录用户都照常渲染；viewer 点击写操作会被服务端拒绝并提示「权限不足」。个别入口的可见性如与上表不符，**以实际权限（服务端拦截结果）为准**。

### 1.3 界面布局与顶栏指示

- 左侧为功能菜单，右上角显示当前用户名与角色标签，点击可「修改密码」或「退出登录」。
- 顶栏标题旁是四个**告警等级计数 pill**（致命/严重/警告/信息），显示当前「告警中」的事件数；点击某个等级可直接跳到「告警中心」并按该等级筛选。
- 顶栏右侧有一个**实时推送状态圆点**：绿色呼吸表示 WebSocket 已连接（新告警弹通知、设备状态自动刷新）；灰色表示未连接（会自动重连，长时间灰色请联系管理员，见《管理员手册》7.3）。

## 2. 仪表盘

本章面向所有值班人员，用于快速了解全网概况。

仪表盘展示设备总数、在线、离线、未知四张计数卡，以及「按类型统计」（网络设备/安全设备/Windows主机/Linux主机/数据库/应用/其他的数量与占比条）。数据每 15 秒自动刷新一次，设备状态变化时经实时推送即时更新，无需手动刷新。

## 3. 网络设备与服务器设备

本章面向需要维护设备台账的运维人员。设备管理按类型拆成两个菜单：「网络设备」（网络设备、安全设备）与「服务器设备」（Windows主机、Linux主机、数据库、应用、其他），两页操作方式相同。

### 3.1 列表与筛选

- 顶部可按关键字（名称 / IP）、设备类型、状态（在线/离线/未知）筛选；「网络设备」页还可按分组筛选。点「查询」生效。
- 列表列：名称、IP 地址、类型、分组、状态、时延、最后在线时间、凭据、监控（开启/关闭）、操作。
- 每行操作：「详情」（进入设备详情页）、「编辑」、「立即探测」（立即执行一次 ping 探测并刷新状态）、「删除」（弹窗确认后删除，**删除会同时清掉该设备的监控历史，谨慎操作**）。

### 3.2 新增 / 编辑设备字段说明

点「新增设备」或行内「编辑」打开对话框：

| 字段 | 说明 |
|---|---|
| 名称 | 选填，默认同 IP；建议起可辨识的名字（如「核心交换机-机房A」） |
| IP 地址 | 必填；设备类型为「应用」时该字段为「目标主机」，允许填域名 |
| 设备类型 | 网络设备/安全设备/Windows主机/Linux主机/数据库/应用/其他，**决定采集方式**（见下） |
| 细分类型 | 仅网络/安全设备显示：网络设备可选交换机/路由器，安全设备可选防火墙；用于拓扑图节点图标，留空按设备类型取默认 |
| 分组 | 选填，可选择已有分组或输入新分组；用于设备筛选与拓扑「分组视图」 |
| 位置 | 选填，如机房/机柜 |
| 凭据 | 选填，主采集凭据：网络/安全/Windows 设备挂 SNMP 凭据，Linux 主机挂 SSH 凭据，数据库挂数据库凭据 |
| 备份凭据(SSH) | 仅网络/安全设备显示，专用于配置备份（SSH 拉取配置），需先在「凭据管理」建好 SSH 凭据 |
| 监控开关 | 关闭后平台停止采集该设备（保留历史数据），常用于设备退役或维护期 |

各设备类型的采集方式对照：网络/安全设备走 SNMP（接口流量、CPU/内存）；Windows 主机走 SNMP（HOST-RESOURCES-MIB）；Linux 主机走 SSH；数据库走只读账号直连探针（MySQL/Oracle/SQLServer）；应用走拨测（见 3.3）。所有类型同时都做 ping 在线/时延监测。

> 同一台主机的 IP 可以挂多个不同类型的设备对象（如一台 Linux 主机同时建「Linux主机」和「数据库」两个对象），但同类型同 IP 只能建一个。

### 3.3 应用（application）类型的拨测配置

设备类型选「应用」后，对话框出现「拨测类型」下拉，共五种，各有专属配置项：

| 拨测类型 | 用途 | 主要配置项 |
|---|---|---|
| HTTP/HTTPS | 探测 Web 服务可用性 | URL（必填）、期望状态码（默认 200~399）、响应关键字（选填，命中响应体才算可用） |
| DNS 解析 | 探测 DNS 解析结果 | 域名（必填）、期望 IP（选填，解析结果须包含该 IP）、DNS 服务器（选填，默认系统解析） |
| TCP 端口 | 探测端口连通性 | 端口（必填）、Banner 匹配（选填，如 `SSH-2.0`） |
| Nginx | 采集 stub_status 指标 | stub_status URL（必填，如 `http://host/nginx_status`） |
| Redis | 采集 Redis 运行指标 | 主机（选填，默认取目标主机）、端口（默认 6379）、密码（选填） |

公共项「超时(秒)」默认 5 秒。拨测产生应用可用性、响应时间等指标，可在设备详情「应用拨测」组查看曲线；配合内置规则「应用不可达」可产生告警。

> 说明：Redis 拨测密码属敏感信息，接口回显一律脱敏为 `******`（任何人看到都不是明文）；编辑时「密码」栏留空表示清除、显示 `******` 表示**保持不变**。另：拨测目标做了 SSRF 防护，不能指向回环（127.0.0.1）、链路本地/云元数据（169.254.x.x）、组播等保留地址。

> 注意：应用设备同样会做 ping 监测；若目标禁 ping，可能出现「拨测正常但 ping 离线」的双重告警，属现状设计。

## 4. 设备详情

本章面向需要查看单台设备运行细节的人员，从设备列表点「详情」进入。

- 顶部基本信息卡：IP、类型、状态、时延、分组、位置、凭据、最后在线时间、系统描述（SNMP 设备）等；「返回列表」回到对应设备页。
- 基本信息下方展示有数据的最新指标（CPU/内存/Ping 时延/进程数/负载等）。

### 4.1 「监控指标」tab

- 时间范围可选：**近 1 小时 / 近 6 小时 / 近 24 小时 / 近 7 天**（默认近 1 小时），切换后全部分区曲线联动刷新。
- 按设备类型分分区展示曲线：「系统」（CPU/内存/Ping/进程数/系统负载）、「接口」（下拉选接口，出速率与利用率两组曲线）、「磁盘」（每块磁盘一张使用率曲线）、「数据库」（多选指标对比）、「应用拨测」。无数据的分区不显示。

### 4.2 「配置备份」tab（仅网络/安全设备）

- 「配置版本」列表按时间列出历史备份（备份时间、内容 Hash、大小），平台每 6 小时自动拉取一次，内容无变化不新增版本。
- 勾选恰好两个版本后点「对比选中版本」，差异逐行显示在列表下方：绿色 `+` 为新增行、红色 `-` 为删除行；两版本一致时提示「两个版本内容一致」。
- 点行内「查看」可阅读该版本完整配置。
- 「立即备份」（仅 admin/operator 可见）手动触发一次拉取，结果提示：已建立首个配置基线 / 检测到配置变更已存新版本 / 配置无变化 / 拉取失败。
- 未绑定「备份凭据(SSH)」的设备此 tab 会提示无法备份，请先在设备编辑中绑定。

## 5. 网络拓扑

本章面向需要查看与维护网络连接关系的人员。拓扑图只展示网络/安全设备及其链路。

### 5.1 查看模式（默认）

- 节点按状态着色边框（在线绿/离线红/未知灰），网络设备按细分类型显示交换机/路由器/防火墙图标。
- 链路样式：实线为手工链路，虚线为自动发现（LLDP/CDP）链路；链路颜色表示两侧接口利用率最大值：绿（正常）→ 黄（>50%）→ 红（>80%），蓝灰色表示无数据。
- 链路标签默认显示，格式为「源端口 ↔ 对端端口」加「↓ 入向速率 ↑ 出向速率」（可用工具栏「链路标签」开关隐藏）。
- **单击链路**弹出实时流量卡（右上角浮卡，随 5 秒轮询刷新双向速率与利用率），点流量卡底部「历史曲线」打开抽屉，可查看该链路两端接口入/出向速率曲线（近 1 小时/6 小时/24 小时/7 天）；单击画布空白关闭浮卡。
- **单击节点**跳转该设备详情页；悬停节点/链路显示基本信息。
- 工具栏：「刷新」「自动布局」（按层次自动重排并保存）、「适应画布」「实际大小」。
- **分组视图**：工具栏最左侧下拉选择分组，只显示该分组内设备及组内链路；各分组的布局位置独立保存，与「全部」视图互不影响。

### 5.2 自动发现

点工具栏「自动发现」，平台通过已入库网络设备的 LLDP/CDP 邻居信息自动识别连接关系并建链，完成后提示扫描台数、发现邻居数、新建链路数与未匹配数。未匹配的邻居（邻居未入库或无法解析到库内设备）不会建链。

### 5.3 编辑模式

打开工具栏「编辑模式」开关后：

- **拖拽节点**调整位置，松手即自动保存布局。
- 点「连线」进入连线模式，依次点击两个节点，在弹出对话框中填写源端口/对端端口（可从已采集接口中选择或手工输入），点「创建」生成手工链路；再点「退出连线」结束。
- **右键链路**弹确认框可删除该链路。

> 拓扑编辑（连线/删链路/布局保存）需要 operator 及以上权限。

## 6. 总线视图

本章面向关注「宿主机—数据库/应用」依附关系的人员。

总线视图以每台宿主机（Linux主机/Windows主机）为一张卡片，卡片顶部是宿主机基座，同 IP 的数据库、应用对象挂在总线上。状态环颜色含义（页面上方有图例）：

- 绿：正常（在线且无告警）
- 橙：有警告/信息级告警
- 红：有严重/致命告警
- 灰：离线/未启用

对象右上角数字角标表示当前「告警中」条数，底色按最高告警等级着色。点击宿主机或挂载对象跳转对应设备详情页。页面每 30 秒自动刷新并联动实时推送。没有挂载数据库/应用的宿主机显示「无挂载对象」。

## 7. 告警中心

本章面向告警值班与规则维护人员。告警中心分七个 tab：告警事件、告警规则、规则模板、通知渠道、静默窗口、日志事件、日志规则。

### 7.1 告警事件

当前与历史告警的统一列表。

- 筛选：状态（告警中/已恢复）、等级（致命/严重/警告/信息）；从顶栏等级 pill 跳入时自动带等级筛选。
- 列表列：等级、规则、设备、指标（含标签，如 `if=GE0/0/1`）、当前值 / 阈值、触发时间、状态、确认人。命中静默窗口的事件带灰色「已静默」标记。
- 操作：
  - **确认（ack）**：表示「已知悉、处理中」，记录确认人；配置了升级时间的规则，超时未确认会自动升一级并重发通知。
  - **关闭**：手动结束该事件（弹窗确认）。指标恢复正常的告警会被系统自动关闭（状态变为「已恢复」），无需手工处理。
- **快照**：点击行首展开按钮，懒加载该事件触发时刻的设备指标快照（当时全部最新指标值），用于回溯现场。

### 7.2 告警规则

规则决定「什么情况下产生什么级别的告警」。平台内置了一批常用规则（带「内置」标记，如设备离线、接口 down、CPU/内存/磁盘/利用率阈值等）。

- 行内开关可启用/停用规则；「新增规则」/「编辑」打开对话框：
  - 规则名称、指标（下拉含全部采集指标，可自定义输入）。
  - 触发条件：比较符（`>` `>=` `<` `<=` `==` `!=`）+ 阈值 + 持续周期数（去抖：连续 N 个采集周期满足才触发，避免抖动）。
  - **动态基线**：比较符选「偏离基线 Nσ」时，与近 7 天同时段（±30 分钟窗口）均值比较，偏离超过 N 倍标准差触发（建议 N=3）；新设备样本不足时不触发。
  - 升级（分钟）：告警超过 N 分钟未确认则等级升一级（封顶致命）并重发通知；0 表示不升级。
  - 等级：致命/严重/警告/信息。
  - 适用范围：可按设备类型、分组、指定设备圈定，三者叠加生效；全不选=全部设备。
  - 标签过滤：按指标标签精确匹配（如 `if=GE0/0/1`），用于只对特定接口/磁盘生效。
- 删除规则需二次确认；内置规则建议用「停用」代替删除。

### 7.3 规则模板

模板是规则的半成品，用于批量复制出正式规则（同名规则已存在则自动跳过，可重复执行）。

- 勾选模板后点「批量生成规则（已选 N）」即可实例化；可先用「覆盖设备类型（选填）」下拉把模板适用范围统一改成某类设备。
- 内置模板（带「内置」标记，由内置规则派生）不可编辑、不可删除；可自建模板，字段比规则多一个「说明」，不含升级时间与启用开关（实例化后在规则里再调）。

### 7.4 通知渠道

告警外发通道，命中规则的告警会推送到全部启用中的渠道。支持三种类型：

| 类型 | 配置项 |
|---|---|
| 邮件 SMTP | 服务器、端口（默认 465/25）、用户名、密码、发件地址、收件人（可多个）、TLS 开关 |
| 钉钉机器人 | Webhook 地址 |
| 企业微信机器人 | Webhook 地址 |

编辑渠道时密钥字段不回显，留空表示不修改；渠道类型不可改（要换类型请删了重建）。渠道密钥加密存储。保存后建议制造一次测试告警验证送达（如临时把某规则阈值调低，或对测试设备拔线验证「设备离线」闭环：触发 → 收到通知 → 恢复 → 自动关闭）。

### 7.5 静默窗口

用于维护期免打扰：窗口时段内命中的告警**事件照常记录**（带「已静默」标记），仅不向外发通知。

- 字段：窗口名称、适用范围（设备类型/分组/指定设备，全空=全部设备）、起止时间、启用开关。
- 列表「状态」列按当前时间显示「生效中/未生效」。典型用法：周末机房维护前建一个覆盖相关分组的窗口。

### 7.6 日志事件

平台通过 Syslog（UDP 1514）与 SNMP Trap（UDP 1162）接收设备主动上报的日志，统一在此检索。

- 筛选：来源 IP、类型（Syslog/Trap）、等级（Syslog 八级：0 紧急 ~ 7 调试，数值越小越严重）、内容关键字、时间范围。
- 列表分页可调每页 20/50/100/200 条。日志量取决于设备侧是否把 syslog/trap 指向平台（配置方法见《管理员手册》4.1、7.9）。

### 7.7 日志规则

日志规则把「收到的日志」升级为「告警事件」：命中条件的日志按设定的告警等级产生告警。

- 匹配条件：来源 IP（留空=任意来源）、内容关键字（子串匹配，留空=不限）、Syslog 等级 ≤ N（仅对 Syslog 生效）。
- 告警等级：致命/严重/警告/信息。
- 注意：来源 IP 未入库为平台设备的日志只存不告；短时间重复命中会做抑制，避免刷屏。

## 8. 报表

本章面向需要做例行统计与向上汇报的人员。报表分两个 tab，均支持「查询」在线查看与「导出 Excel」下载 `.xlsx` 文件。

### 8.1 可用率报表

- 条件：日期范围（默认近 7 天）、设备类型（可选）。
- 输出：设备 × 日期 的采集点数、在线点数、可用率；可用率着色：100% 绿、低于 99.9% 红、介于其间橙、无数据显示「-」。
- 导出文件名 `可用率报表.xlsx`。

### 8.2 流量报表

- 条件：日期范围、粒度（按日/按月）、Top N（可选，只看流量最大的前 N 个接口）。
- 输出：设备 × 接口 × 周期 的入/出向均值、峰值与 P95 速率。
- 导出文件名 `流量报表.xlsx`。

> 报表基于 5 分钟聚合数据，最长可追溯 180 天。

## 10. 自动发现

本章面向批量接入设备的运维人员，用于扫描 IP 段并把存活设备批量入库。

1. 在「发起扫描」卡片的文本框输入扫描目标：支持网段（`192.168.1.0/24`）、范围（`192.168.1.1-192.168.1.254`）、单 IP，可用逗号、分号或换行混合分隔；无法解析的行会被列出并忽略。
2. （选填）挂一个 SNMP 凭据：扫描时顺带读取设备系统名称/描述，便于识别设备类型。
3. 点「开始扫描」，进度条实时显示进度；扫描结果中**在线且未入库**的 IP 可勾选。
4. 点「批量入库（已选 N 台）」，在对话框统一设置设备类型、分组、位置、凭据，确认入库；结果提示成功与跳过（已存在）数量。
5. 下方「历史扫描任务」保留最近 20 次任务，可回看结果。

扫描结果会自动回写 IPAM 台账（标记来源为「扫描发现」）。发起扫描与入库需要 operator 及以上权限。

## 11. IP 地址管理（IPAM）

本章面向需要掌握 IP 占用与终端接入位置的人员。台账数据来自 IPAM 周期采集（网络设备 ARP/MAC 表）与自动发现扫描回写。

### 11.1 子网使用情况（/24 网格）

每个 /24 子网一块 16×16 方格，一格一个 IP，颜色含义：

| 颜色 | 含义 |
|---|---|
| 绿 | 在线 |
| 黄 | 近 7 天活跃 |
| 灰 | 更早（7 天前见过） |
| 浅灰 | 未见（无记录，不可点） |

子网标题行显示「共 N · 在线 N · 7天 N」，点击标题按该子网过滤下方清单；点击有记录的格子按该 IP 过滤。悬停格子可查看 MAC、主机名、接入设备/端口、来源、最近在线时间。

### 11.2 终端清单

- 筛选：IP 关键字、MAC 关键字、子网、来源（扫描发现/ARP 表/MAC 表）、是否白名单。
- 列：IP、MAC、主机名/备注、来源、接入设备、接入端口、首次发现、最近在线、白名单开关。
- **白名单**：新发现的终端会产生「新终端接入」提示事件；确认是合法终端后打开白名单开关，以后该终端不再触发此类提示（交换机批量上线初期事件较多，建议先把存量终端批量确认）。白名单开关与备注编辑需要 operator 及以上权限（viewer 界面上为禁用态）。
- **备注**：点「编辑」为主机名/备注列填写说明（留空清除）。

## 12. 凭据管理

本章面向维护采集凭据的人员。所有采集用的账号密码/团体名统一在此录入，加密存储，设备侧只作引用。

凭据共四种类型：

| 类型 | 用途 | 字段 |
|---|---|---|
| SNMP v2c | 网络/安全/Windows 设备采集 | 团体名、端口（默认 161） |
| SNMP v3 | 同上（高安全场景） | 用户名、认证协议（SHA/MD5/无认证）与认证密钥、加密协议（AES/DES/无加密）与加密密钥、端口 |
| SSH | Linux 主机采集、网络设备配置备份 | 用户名、密码、端口（默认 22） |
| 数据库 | 数据库探针 | 数据库类型（MySQL/Oracle/SQL Server/PostgreSQL）、用户名（建议只读监控账号）、密码、端口、库名（Oracle 为服务名） |

要点：

- **编辑凭据时类型（kind）不可改**（下拉禁用）；要换类型请删除后重建。
- 编辑时所有密钥字段留空表示不修改。
- 凭据内容加密落库，列表与编辑界面均不回显明文；密钥由服务端 `OPS_FERNET_KEY` 保护，更换该密钥会导致全部凭据失效（见《管理员手册》6.2）。
- 删除被设备引用的凭据前，请先在相关设备上解除绑定。

## 13. 用户管理与审计日志（仅 admin）

本章仅面向管理员；非 admin 用户无此两个菜单，直接访问会被拦截并提示「仅管理员可访问该页面」。

### 13.1 用户管理

- 「新增用户」：填用户名、密码（至少 8 位且同时含字母与数字）、角色（admin/operator/viewer，默认 viewer）。
- 列表行内可直接改角色（下拉选择即生效）、禁用/启用、删除用户。
- 保护规则：不能禁用/降级/删除自己；系统至少保留一个启用状态的 admin（最后一名管理员不可降级或禁用）。
- 禁用立即生效：被禁用户无法再调任何接口；已登录的会话在下一次操作时失效。

### 13.2 审计日志

记录平台关键操作：登录成功/失败、设备/凭据/规则/静默/渠道/用户的增删改、修改密码、手动探测等。

- 筛选：用户名、动作（如 `login`、`device_create`）、时间范围；列表列：时间、用户、动作、对象、详情、来源 IP。
- 按时间倒序分页查看，用于安全审计与操作回溯。
