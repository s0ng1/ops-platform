# 内网运维管理平台 · 总体方案（2026-07-29 修订版）

> 2026-07-21 初稿定稿；本版按第 1~9 期实际交付现状修订（架构、技术栈、进度与初稿相比已有大量演进，以本版为准）。
> 对标北塔（Broadview）类 NMS，自研轻量版。监控网络设备、安全设备、服务器、数据库、应用，支持自动/手工拓扑、线路流量、阈值告警、配置备份、Syslog/Trap、IPAM、报表与大屏。

**已确认的决策**：完全自研 · Python 全栈（FastAPI + Vue 3）· 中型规模（200~2000 台）· Linux 服务器部署 · **不引入 Redis**。

## 一、总体架构

```
┌──────────────────── 浏览器（Vue 3 SPA）────────────────────┐
│ 仪表盘 │ 设备 │ 拓扑/总线 │ 告警中心 │ 报表 │ 大屏 │ IPAM │ 审计 │
└──────────────────────────┬─────────────────────────────────┘
                    HTTP / WebSocket（/api/ws）
┌──────────────────────────▼─────────────────────────────────┐
│  FastAPI 后端（uvicorn，REST + WS 推送，单进程）            │
│  ├─ API 层：设备/拓扑/告警/报表/审计/用户/凭据/日志/IPAM    │
│  ├─ 采集调度器：任务注册表 + 协程池（接口/系统 60s、库 300s）│
│  ├─ 采集器：SNMP / Ping / SSH / 数据库探针 / 应用拨测       │
│  ├─ 告警引擎：阈值+基线规则 → 去抖/静默/升级 → 通知         │
│  ├─ Syslog / SNMP Trap 接收器（UDP 1514 / 1162）            │
│  └─ 拓扑服务：LLDP/CDP 自动发现 + 手工连线                   │
└───────┬─────────────────────────────────────────────────────┘
   PostgreSQL + TimescaleDB（结构数据 + 时序指标同库）
```

- **三个容器**：`web`（nginx 托管 SPA + /api 反代）、`api`（业务 + 采集 + 告警 + 接收器）、`db`（timescale/timescaledb:latest-pg15）。
- **无 Redis**：任务分发用 asyncio 协程池、实时状态用进程内广播（`core/broadcast.py`）、WS 推送单进程。压测结论（`docs/压测报告.md`）确认瓶颈在告警引擎与 DB 会话池，与队列/缓存/推送无关，故不引入 Redis；多实例部署前才需 Redis pub/sub（只改 `core/broadcast.py`）。

## 二、技术选型

| 层 | 选型 | 说明 |
|---|---|---|
| 后端 | Python 3.11+（实测 3.13）+ FastAPI + asyncio | 异步 SNMP 轮询天然契合协程 |
| 采集 | pysnmp 7.1（SNMP v2c/v3）、asyncssh、ping、pymysql/oracledb/pytds/psycopg 探针 | 无 Agent，标准协议，内网设备零改造 |
| 关系 + 时序 | PostgreSQL + TimescaleDB 扩展 | 结构数据与指标同库，少维护一套 |
| 前端 | Vue 3 + Vite + Element Plus | 中文运维场景生态成熟 |
| 拓扑图 | AntV G6 v5 | 拖拽、自定义节点、边流量动画 |
| 图表 | ECharts | 流量曲线、仪表盘、大屏 |
| 部署 | docker-compose（db/api/web 三服务） | 内网交付，离线打包（`deploy/offline-pack.sh`） |

## 三、功能模块（第 1~8 期已交付）

1. **设备管理（CMDB）**：网络/安全/Windows 主机/Linux 主机/数据库/应用/其他七类；`(ip, type)` 唯一（一机多对象）；凭据 Fernet 加密；IP 段自动发现入库；网络设备细分 switch/router/firewall。
2. **监控采集（全无 Agent）**：网络/安全 SNMP（接口流量/状态、CPU、内存，Cisco/华为/H3C 指纹）；Windows SNMP（HOST-RESOURCES-MIB）；Linux SSH（/proc、df）；数据库只读直连（MySQL/Oracle/SQLServer/PostgreSQL）；应用拨测（http/dns/tcp/nginx/redis）；ping 在线/时延；IPAM（ARP/MAC 表）；配置备份（SSH 拉配置 + sha256 去重 + diff）。
3. **拓扑图**：LLDP/CDP 自动发现（并行）、手工连线、G6 深色画布、分组子拓扑、链路实时流量 + 历史曲线。
4. **告警**：阈值 + 动态基线规则、去抖、静默窗口、升级、告警时刻快照、规则模板；通知 SMTP/钉钉/企业微信；Syslog/Trap 日志事件 → 告警。
5. **报表与大屏**：可用率、流量日报/月报（导出 Excel xlsx）；科技风大屏（指标卡/告警滚动/TopN 流量）。
6. **权限与审计**：RBAC 三角色（admin/operator/viewer，后端强制）；操作审计日志；用户禁用/改角色。
7. **其他视图**：宿主机-数据库总线视图（/bus）。

**明确不做的扩展对象**（现场无验证对象/超出轻量定位）：虚拟化、存储（SMI-S）、动环、无线、3D 机房/面板图、DIYOPS/ITSM、多租户、NetFlow、中间件 JMX/WebLogic/Tomcat 等。

**已知边界**：Windows/Linux 磁盘 IO（标准 SNMP 盲区，WMI 可选补充未做）、光功率/光模块传感器、短信网关通知、PDF 导出（报表现只出 xlsx）。

## 六、风险与注意点

- **SNMP 指纹库**：已覆盖 Cisco/华为/H3C + 通用 MIB2 兜底；锐捷等其他厂商 OID 待现场补。
- **Windows 磁盘 IO / 光功率**：标准 SNMP 盲区，属已知边界，现场按需另议。
- **数据库监控账号**：各库需建只读监控账号（Oracle 需 SELECT_CATALOG_ROLE、SQLServer 需 VIEW SERVER STATE、PostgreSQL 建议 pg_monitor），实施前与 DBA 协调。
- **内网离线交付**：依赖离线打包（`deploy/offline-pack.sh` 产出镜像 + wheels + 手册）。
- **单进程假设**：限流/WS 票据/广播均为进程内存态，多实例部署前需 Redis 或共享存储（沿用既有决策）。
